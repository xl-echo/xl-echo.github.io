# 虎杖：根黄茎斑花白，火气透出体表后化为寒

## 一、同一株植物上，从下到上有三种颜色

**地下，根状茎的切面是黄的。**外皮黑褐，剖开则黄色鲜明显著，射线放射状。这是药材性状里最醒目的一条。

**地上，茎秆是绿的，散生红色或紫红色斑点。**茎直立粗壮，中空，具纵棱，节节分明。那些红褐色斑点不是漫布，是一点一点散在表皮上。

**顶梢，花是淡绿近白的。**花序圆锥状，腋生，花被五深裂；《中国植物志》记作"淡绿色"，另有记述作"白色"，民间多称密生白色小花。花在枝的末端。

三种颜色，黄在内，绿兼红在中间，白在最上。这不是随手罗列——它们排在同一条路上。

## 二、这条路上的事：火被透发走了

先看它长在哪里。虎杖生于山坡灌丛、山谷、路旁、田边湿地，溪边最盛，海拔一百四十米到两千米。它不挑向阳干燥的高处，专在潮湿低下的地方成丛——而湿与热在浅土里最易胶结，散不掉，这就是它根下要处理的那股郁火。

**黄色是火退之象。**五行之中火色为赤，赤极则退，退而见黄，黄是土之色。根茎切面见黄，说明那团火在根里已经退过一层——不是被压住，是走过了头。

**红褐色斑点是火透达于表。**火的去向是向上，根里的火借生发之势从地下往上走，走到茎上。茎秆本体仍是青绿，只散着红点，说明火不是漫布整个茎身，是被一个一个点地送出来，透到表皮。

**到顶端，花成了淡绿近白。**火走到末梢，透尽。赤没了，黄淡了，只剩近乎无色的白。这一步就是你说的话：**火气被透发成了寒气**。

所以看虎杖这一株，是一条完整的路径：**火在浅土里郁着，被根托起来，沿茎向上透，散在皮上，最后在顶端透尽成白。**它不是在体内存火，是一路把它送出去。

## 三、这条路径就是它的药性

药性上它味微苦，性微寒（《名医别录》原作微温，唐宋以后多改微寒，此为版本歧异）。这个"微寒"不是生来就寒——是火透发到最后剩下的结果。火既已透尽，留在药里的就不是燥烈之气，而是清降之气。

由此几件事都顺下来：

**它清的是一股要往外走的火，不是一把要压下去的火。**所以它清热之余兼能通行——利湿退黄、清热解毒、散瘀止痛，一起见于同一味药，不矛盾。湿热黄疸、淋浊带下，正是它生境里那种湿与热胶结的场面。

**它的路径是从里到表、从下到上。**火郁则血滞，透则血行，故能破留血、通经闭、散跌打瘀肿。

**火透尽处是白，也是上焦。**花恰开在顶端，归肺；肺居上焦，主气之宣降。虎杖能化痰止咳，治肺热咳嗽痰稠难出——正是这条路径的末端落点。

**根茎在地下，性又能降。**苦降走泄，郁热既可从表透，也可从下出，故兼能泻下通便。一个上透，一个下泄，两条出口。

## 四、收束

《本草纲目》说"杖言其茎，虎言其斑也"，只讲了名字，没讲这株植物在做什么。

其实它在做一件事：把浅土里郁住的那股火，一路透到末梢去，直透到没有颜色为止。根上退成黄，茎上现成斑，花上结成白。

本草收它入药，收的不是它的形状，是这条已经走完的路径。所以它药性微寒而能散能通——**它的寒，是从火里透出来的寒。**
