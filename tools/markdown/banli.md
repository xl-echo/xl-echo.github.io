# 尖刺敛气机，深根承土性，不仅健脾还能补肾的野果——板栗

> 温馨提示：本文仅从传统本草象理文化角度分享植物知识，仅供学习参考，不具备诊疗指导作用。草药切勿自行采摘、服用，身体不适请咨询专业医师。


![](./images/banli-1.jpg)

板栗植株直根向下深扎，侧根亦向四方土层纵深延展，整株根系深伏厚土，禀赋土层敦厚持重的土性；果实外层密布尖刺皮毛，皮毛主卫外固护，紧紧包裹内里果仁，待到养分敛藏充足才会自行开裂，尽显 “藏满而后泄” 的自然气机之象，且板栗秋令成熟，种实完整吸纳秋金肃降之气，兼具收敛封藏生机的特质，一身物性大势归于肃降、敛藏。


![](./images/banli-2.jpg)

其味甘、性温，甘味专能补益中土，温性可运化驱散脾胃虚寒，依托其先天敦厚土性与秋金降敛之能，气机直入中焦、下焦，故而具备健脾和胃、补肾填精的功用；但其敛藏之性有极，若过量服食便会下气走泄，恰合果皮尖刺护藏果仁、藏足方开裂泄气的外在表象，藏蓄充盈之后气机自然外泄，多食下气便是此气机规律在人体上的直观体现。


![](./images/banli-3.jpg)

良种板栗（市面上的水果板栗）多有各种催化，敛藏之性相对较弱，种子的生机也失去十之七八。催化的本质是加快生长过程，加强生长力，属于外力引导，不是内里生命的自由成长，天地气机的承载自然减弱。


![](./images/banli-4.jpg)

> 相比较山野自由生长的板栗，其敛藏肾阳的能量较弱，同时能量更加驳杂。
